Place your professional headshot here, e.g. profile.jpg (recommended: square, at least 500x500px).

The current design intentionally does not use a photo in the hero section (it uses a
terminal-style code card instead), so adding a photo is optional. If you'd like to add one,
a natural spot is the "About" section — wrap it in a rounded card and reference it from
index.html, e.g.:

  <img src="assets/images/profile.jpg" alt="Kaung Myat Kyaw" class="img-fluid rounded-4">

Other assets you may want to add here:
- favicon.png / favicon.svg (browser tab icon)
- resume.pdf (so the "Get in Touch" or a "Download CV" button can link to it directly)
- og-image.jpg (for social share previews, 1200x630px)
